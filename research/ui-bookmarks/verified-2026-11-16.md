Legend:
- **live**: `yes` = HTTP 200 with real content. "403 to bots" = the site blocks scripted requests; it was either opened in a real browser (said so) or is a well-known site assumed live.
- **pricing** marked *(gk)* comes from general knowledge of a well-known site, not re-read on the page today. "unverified" = could not confirm.
- **licence** is GitHub's detected SPDX id unless a note says the licence file was read.
- **notes** starting with **DROP** = personal/account-specific or not UI-related. **MARGINAL** = generic tool or learning site, low value for a UI component catalog.
